# Getting Started with Three.js

This project is a simple introduction to using [Three.js](https://threejs.org/), a JavaScript 3D library. It demonstrates how to set up a scene, camera, renderer, and basic geometries with lighting and controls.

## Features

- **Basic setup: Scene, Camera, Renderer**: Basic setup for rendering 3D objects.
- **Key listeners and Orbit Controls**: Allows smooth camera movement around the scene.
- **Geometries**: Includes an icosahedron with both solid and wireframe materials.
- **Lighting**: Uses a hemisphere light to illuminate the scene.
- **Animation Loop and requestAnimationFrame**: Continuously renders the scene and updates controls.

## Tutorial

This project was created by following the tutorial: [Getting Started with Three.js](https://www.youtube.com/watch?v=UMqNHi1GDAE).

## How to Run

1. Clone this repository.
2. Open `index.html` in a browser.
3. Explore the 3D scene!

## Dependencies

- [Three.js](https://threejs.org/) (loaded via CDN)
